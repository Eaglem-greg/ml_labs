# Производные и NumPy

Лабораторная работа по численному вычислению производной функции `sin(x)`.

В ноутбуке сравниваются:

- правая конечная разность;
- центральная конечная разность;
- `numpy.gradient`;
- аналитическая производная `cos(x)`.

Файл `derivative_visualization.png` содержит результат визуализации из ноутбука.

## Запуск

Из корня репозитория:

```bash
jupyter notebook labs/00_numpy_derivatives/derivatives_and_numpy.ipynb
```

Необходимые библиотеки: `numpy`, `matplotlib` и Jupyter Notebook или JupyterLab.
